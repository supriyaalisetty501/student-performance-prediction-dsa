## Long-Form Description (for repo homepage / pinned about section)

**AI-Powered Student Performance Prediction & Learning Recommendation System**

A command-line Python application that demonstrates practical Data
Structures & Algorithms — Lists, Dictionaries, a manually implemented
Linear Search, and a manually implemented Merge Sort — applied to a real
educational dataset (UCI "Student Performance Data Set").

The system loads real student records, lets you search and sort them
using algorithms built from scratch (no built-in `sort()` shortcuts),
classifies each student into one of five performance categories using
transparent rule-based logic, generates a personalized learning
recommendation per category, and produces five Matplotlib visualizations
summarizing class-wide trends.

**Highlights:**
- 🗂️ Real dataset (not synthetic) — UCI Student Performance Data Set
- 🔍 Manual Linear Search — O(n) — no built-in shortcuts
- 🔀 Manual Merge Sort — guaranteed O(n log n), stable — no built-in `sort()`
- 🎯 Rule-based, fully explainable prediction engine (5 categories)
- 📊 5 auto-generated Matplotlib charts (distribution, attendance, marks, study hours, correlation heatmap)
- 🏗️ Production-style architecture: type hints, docstrings, logging, custom exceptions, input validation
- ✅ Zero paid APIs, zero external ML models — 100% free & transparent
